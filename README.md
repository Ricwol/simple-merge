# Simple Merge

`Simple Merge` is a small desktop application that helps you merge
multiple PDF files into one single PDF.
The program is easy to use and guides you with clear buttons and simple actions.

## What Simple Merge Does
+ Accepts two or more PDF files
+ Lets you arrange the order of the files
+ Merges all selected PDFs into a single output file
+ Saves the merged file to any folder you choose
+ Supports drag and drop to add files quickly
+ Accepts only PDF files

## What Simple Merge Does Not Do
+ It does not edit PDF contents
+ It does not split pages
+ It does not convert files

## How To Use Simple Merge
1. Start the programm.
2. Drag and drop your PDF files into the list area, or click the `Add File(s)` button.
3. Use the arrow buttons to move the files up or down and set the merge order.
4. Remove files with the `Remove File(s)` button or clear the entire list.
5. When you are ready, press the `Merge` button.
6. Choose a name for the output file or use the default name "merged.pdf".
7. Save the file. The merge is completed.

### Important Notes
+ You __must__ select at least two PDF files to create a merged file.
+ The application will ignore invalid or duplicate files.
+ After merging, the list clears automatically to help prevent accidents.
